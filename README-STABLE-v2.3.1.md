# Para Makinesi Binance v2.3.1

BlackBox Time & Close Analysis sürümü.

- Açılış mesajına gerçek işlem açılış saati eklendi.
- Kapanış mesajına açılış saati, kapanış saati ve işlem süresi eklendi.
- Kapanışta açılış uyumu → kapanış uyumu karşılaştırması eklendi.
- Kapanışta Bollinger bölgesi değişimi gösterilir.
- Aktif pozisyon ana rapor özetinde açılış zamanı ve süre görünür.
- Strateji mantığı değiştirilmedi; BlackBox ölçüm katmanı genişletildi.
