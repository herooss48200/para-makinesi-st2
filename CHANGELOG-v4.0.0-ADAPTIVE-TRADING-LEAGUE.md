# AGROS v4.0.0 — Adaptive Trading League

Nihai üç günlük gözlem paketi.

- Dynamic League: sayı sınırı olmadan kalite bazlı Premier.
- Dynamic Exit Intelligence: DNA + rejim + volatilite bazlı exit seçimi.
- Shadow Learning: alt lig işlemleri öğrenir, Premier kasasına karışmaz.
- Premier Auto Selection, realtime promotion/relegation.
- Dynamic regime detection ve dynamic exit selection.
- Live confidence, league dashboard ve Telegram League.
- Premier/Shadow istatistikleri ayrı tutulur.
- Promotion history, exit history ve DNA Story kalıcı JSON/JSONL kayıtları.
- Açılış kimliği dondurulur; sonradan lig değişimi geçmiş sonucu değiştirmez.
- Gerçek emir filtresi kapalıdır; mevcut sanal öğrenme ve aktif pozisyonlar korunur.
