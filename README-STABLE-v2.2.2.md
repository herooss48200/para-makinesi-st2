# Para Makinesi Binance v2.2.2 - BlackBox Telegram Cards Hotfix

Bu sürüm strateji mantığını değiştirmez.

## Düzeltmeler

- Telegram pozisyon açılış mesajına BlackBox açılış fotoğrafı eklendi.
- Telegram pozisyon kapanış mesajına açılış fotoğrafı, kapanış fotoğrafı ve trend değişimi eklendi.
- BTC ve coin için 5m / 15m / 1h / 4h SuperTrend yönleri telefondan okunabilir hale getirildi.
- BlackBox CSV/JSONL kayıtları v2.2.1 ile aynı formatta korunur.
- Kasa hotfix v2.2.1 tabanı korunur.
