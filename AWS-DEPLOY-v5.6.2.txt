AGROS ST2 v5.6.2 RECOVERY SPRINT — AWS DEPLOY

1) Mevcut ST2 data klasörünü mutlaka yedekleyin:
   cp -a data data-backup-$(date +%Y%m%d-%H%M%S)

2) ZIP içeriğini mevcut ST2 uygulama klasörüne açın.
   Mevcut .env ve data klasörünü silmeyin/değiştirmeyin.

3) Bağımlılık ve test:
   npm ci
   npm run verify:v562
   node test_st2_identity_isolation.js

4) PM2:
   pm2 restart agros-st2 --update-env
   pm2 save

5) İlk canlı doğrulama:
   pm2 logs agros-st2 --lines 200
   grep -RniE "ST2 RENKO GİRİŞ EVRİMİ|Tarihsel hafıza kurtarıldı|Kapanış köprüsü|PRICE-PATH REPLAY" logs-st2 2>/dev/null | tail -100

KORUMA:
- Trade Engine, emir açma, Stop, BE ve Exit davranışı değiştirilmedi.
- AWS data klasörü teslim ZIP'iyle ezilmemelidir; tarihsel kurtarma mevcut/legacy state'i buradan bulur.
